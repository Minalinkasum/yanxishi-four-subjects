# 研习室 · 四科模拟

面向2026年12月初试（2027级）的个人考研练习网站。

## 学科与内容

- 101 思想政治理论：模拟卷、时政热点与周年事件、教材考点对应、八套肖八交互练习。
- 201 英语（一）：完形、阅读、新题型、翻译与写作。
- 706 中国语言文学综合知识。
- 808 中国语言文学专业基础。

专业课覆盖中国古代文学、中国现当代文学、外国文学、文学理论、语言学、古典文献学和古文字学。

## 使用方式

直接打开 `dist/index.html`，或打开根目录 `四科研习室.html`。

也可用 Python 启动本地静态服务器：

```sh
python -m http.server 8000 --directory dist
```

然后访问 http://localhost:8000 。项目采用原生 HTML、CSS 和 JavaScript，无需安装依赖或构建。

## 功能

- 整卷模拟、自由练习与考点练习。
- 考试计时、自动保存、交卷与主观题自评。
- 参考答案、解析、材料来源和评分要点。
- 错题、收藏、复盘笔记与学习备份导入导出。
- 肖八按题号作答，不附答案解析。

## 文件

- `dist/index.html`：网页入口。
- `dist/app.js`：练习交互。
- `dist/data.js`：题库、答案、资料来源和专题。
- `dist/style.css`：页面样式。
- `dist/assets/`：试卷参考附件。
- `四科研习室.html`：离线整合入口。
- `使用说明.txt`：详细使用说明。

## 学习数据

答题记录、收藏、计时、自评和笔记保存在使用者浏览器的 localStorage 中，不上传服务器。不同网址、浏览器与设备分别保存。换设备或清理数据前先导出学习备份。

仓库包含学习程序、题库和页面引用的附件，不包含个人浏览器答题记录、账号凭据或原始复习资料目录。肖八等第三方资料的权利归原权利人所有，本项目用于个人学习。
